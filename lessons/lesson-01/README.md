# 第1讲学生操练包

## 用途

本包配套《交通大数据分析与应用》第1讲“交通大数据概述”。数据均为课程模拟数据，不是实际监测数据。

## 课堂任务

1. 在三类数据源中选择一种，确认观察对象、时间粒度和空间粒度；
2. 修改SELECTED_SOURCE，重新生成数据卡片；
3. 写出该数据源能够回答的问题和不能直接回答的问题各一项；

## 使用

1. 保持`data`、`outputs`和Notebook的相对位置不变；
2. 选择Python 3内核；
3. 从第一个单元开始运行并修改`TODO`参数；
4. 确认`outputs/自检结果.txt`为`PASS`。

不要在课堂上临时安装软件包。出现问题时记录失败单元格和报错首尾行。
