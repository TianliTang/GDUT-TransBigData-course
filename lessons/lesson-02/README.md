# 第2讲学生操练包

## 用途

本包配套《交通大数据分析与应用》第2讲“交通数据结构与Python分析工作流”。数据均为课程模拟数据，不是实际监测数据。

## 课堂任务

1. 修改DETECTOR_IDS并比较两个方向的数组聚合结果；
2. 按detector_id连接路段元数据，核对连接前后的行数；
3. 把15分钟数据重采样为小时数据并解释聚合函数；

## 使用

1. 保持`data`、`outputs`和Notebook的相对位置不变；
2. 选择Python 3内核；
3. 从第一个单元开始运行并修改`TODO`参数；
4. 确认`outputs/自检结果.txt`为`PASS`。

不要在课堂上临时安装软件包。出现问题时记录失败单元格和报错首尾行。
