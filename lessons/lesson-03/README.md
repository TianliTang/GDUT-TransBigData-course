# 第3讲学生操练包

## 用途

本包配套《交通大数据分析与应用》第3讲“数据质量、时空特征与探索性分析”。数据均为课程模拟数据，不是实际监测数据。

## 课堂任务

1. 完成四类质量问题计数并决定处理规则；
2. 修改SPEED_MAX，观察有效样本量和均值如何变化；
3. 输出质量报告和路段—小时热力图；

## 使用

1. 保持`data`、`outputs`和Notebook的相对位置不变；
2. 选择Python 3内核；
3. 从第一个单元开始运行并修改`TODO`参数；
4. 确认`outputs/自检结果.txt`为`PASS`。

不要在课堂上临时安装软件包。出现问题时记录失败单元格和报错首尾行。
