# 第4讲学生操练包

## 用途

本包配套《交通大数据分析与应用》第4讲“统计推断与线性回归”。数据均为课程模拟数据，不是实际监测数据。

## 课堂任务

1. 修改CONFIDENCE_LEVEL并比较区间宽度；
2. 按时间先后划分训练集与检验集，计算MAE和R²；
3. 选择一个系数，写出包含单位和控制条件的解释；

## 使用

1. 保持`data`、`outputs`和Notebook的相对位置不变；
2. 选择Python 3内核；
3. 从第一个单元开始运行并修改`TODO`参数；
4. 确认`outputs/自检结果.txt`为`PASS`。

不要在课堂上临时安装软件包。出现问题时记录失败单元格和报错首尾行。
