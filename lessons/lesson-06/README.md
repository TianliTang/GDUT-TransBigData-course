# 第6讲学生操练包

## 用途

本包配套《交通大数据分析与应用》第6讲“时间序列分析与交通状态预测”。数据均为课程模拟数据，不是实际监测数据。

## 课堂任务

1. 把WINDOW从3改为6，比较移动平均的平滑程度和误差；
2. 把ALPHA从0.4改为0.8，说明指数平滑对新变化的响应怎样改变；
3. 找出AR(4)绝对误差最大的三个时段，并结合原序列解释可能原因；

## 使用

1. 保持`data`、`outputs`和Notebook的相对位置不变；
2. 选择Python 3内核；
3. 教师/参考答案版执行Restart Kernel and Run All；学生版从第一个单元开始运行并修改`TODO`参数；
4. 确认`outputs/自检结果.txt`为`PASS`。

不要在课堂上临时安装软件包。出现问题时记录失败单元格和报错首尾行。
