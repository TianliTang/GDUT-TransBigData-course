# 第7讲学生操练包

## 用途

本包配套《交通大数据分析与应用》第7讲“主成分分析与机器学习简介”。数据均为课程模拟数据，不是实际监测数据。

## 课堂任务

1. 把N_COMPONENTS设为2和3，比较累计贡献率与压缩程度；
2. 找出PC1、PC2绝对载荷最大的变量，并给出有依据的名称；
3. 把THRESHOLD设为0.35和0.65，比较Precision、Recall与报警数量；

## 使用

1. 保持`data`、`outputs`和Notebook的相对位置不变；
2. 选择Python 3内核；
3. 教师/参考答案版执行Restart Kernel and Run All；学生版从第一个单元开始运行并修改`TODO`参数；
4. 确认`outputs/自检结果.txt`为`PASS`。

不要在课堂上临时安装软件包。出现问题时记录失败单元格和报错首尾行。
