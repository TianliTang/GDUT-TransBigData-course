# 第8讲学生操练包

## 用途

本包配套《交通大数据分析与应用》第8讲“优化思想、支持向量机与超参数”。数据均为课程模拟数据，不是实际监测数据。

## 课堂任务

1. 修改COMPARISON_PARAMS，比较较小和较大的C、gamma组合及其验证AP与边界；
2. 检查最佳组合附近的验证表现是否稳定，不只抄写best_params_；
3. 解释为什么StandardScaler必须放进Pipeline、测试集不能参与搜索；

## 使用

1. 保持`data`、`outputs`和Notebook的相对位置不变；
2. 选择Python 3内核；
3. 教师/参考答案版执行Restart Kernel and Run All；学生版从第一个单元开始运行并修改`TODO`参数；
4. 确认`outputs/自检结果.txt`为`PASS`。

不要在课堂上临时安装软件包。出现问题时记录失败单元格和报错首尾行。
