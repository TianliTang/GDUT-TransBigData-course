# PEMS-BAY课程数据包说明

## 1. 先看这一页

本数据包用于《交通大数据分析与应用》课程项目。学生无需另行注册、下载或替换数据。课程项目中应使用本数据包的固定版本，以保证不同小组的结果可以比较。

数据记录的是325个高速公路检测站的5分钟平均速度。时间范围为2017年1月1日00:00至2017年6月30日23:55，共52,116个时间点。数据采用“宽表”结构：每一行是一个时间点，每一个检测站编号是一列。

> 重要边界：本数据包只有速度、检测站坐标和站点间距离关系，没有流量、占有率、车道数、事故、天气、道路施工或控制措施数据。因此可以分析运行状态、时空关联、预测和预警，但不能仅凭本数据证明拥堵原因或某项措施的因果效果。

## 3. 主数据怎样理解

### 3.1 `pems_bay_speed.csv.gz`

- 观测单位：一个检测站在一个5分钟时间点的平均速度；
- 行：52,116个时间点；
- 检测站列：325列；
- `timestamp`：数据中记录的当地日期时间，文件本身未写入时区偏移；
- 其余列名：检测站编号；
- 数值单位：英里/小时（mph）。

例如，`400001`列在某一行的数值是检测站400001在该时间点的速度，不是流量，也不是车辆数。

### 3.2 `stations.csv`

每行对应一个检测站：

- `sensor_order`：该站点在速度矩阵中的列序号，从0开始；
- `sensor_id`：检测站编号，应按字符串读取；
- `latitude`、`longitude`：WGS84经纬度，可用于绘制点位分布。

检测站是点观测位置，不等同于完整道路路段。仅凭经纬度也不能判断行驶方向、车道类型或道路功能。

### 3.3 `sensor_distances.csv.gz`

每行表示一个有向站点对：

- `from_sensor_id`：起点检测站；
- `to_sensor_id`：终点检测站；
- `distance`：原始仓库提供的距离值。

该文件不是所有站点两两组合的完整距离矩阵，`from → to`与`to → from`也不一定同时存在。课程审计表明其数量级与米一致，但上游文件没有明确写出单位，因此本课程将其主要作为相对距离和图连接依据。不得把它直接解释为精确道路里程、行驶时间或上下游方向。

## 4. 已知数据质量问题

### 4.1 时间并非完全连续

全时段按5分钟应有52,128个时间标签，数据实际有52,116个。2017年3月12日02:00至02:55的12个时间标签共同缺失，前后形成一次65分钟间隔。这个全网同步缺口与当地时间切换相符，不应直接解释为325个检测器同时故障。

进行滞后、滚动窗口、持续时间或预测分析时，应先检查相邻时间差是否确为5分钟。不要在没有说明的情况下把缺少的12行自动补成正常速度。

### 4.2 0值需要单独处理

完整速度矩阵中没有空白值，但有304个0值，分布在230个检测站。0值既可能表示编码的无效或缺失观测，也可能被误解为真实完全停车。建议将0值先标记为数据质量候选，并至少比较以下两种处理对结论的影响：

1. 将0值暂按缺失值处理；
2. 保留0值，但在图表和评价指标中单独说明。

不建议直接用0值计算MAPE；分母为0会使结果失真。

### 4.3 不能从现有字段判断的内容

本数据包不能直接判断：

- 某次低速是否由事故、天气、施工或需求增长造成；
- 检测站属于哪条道路、哪个方向或哪类车道；
- 道路通行能力、流量—密度关系或车辆延误总量；
- 某项管理措施实施后的因果效果。

这些内容可以作为局限和后续数据需求提出，但不能作为已经由本数据验证的结论。

## 5. 最小读取示例

```python
from pathlib import Path
import pandas as pd

data_dir = Path("学生数据包")

speed = pd.read_csv(
    data_dir / "pems_bay_speed.csv.gz",
    parse_dates=["timestamp"]
)
stations = pd.read_csv(
    data_dir / "stations.csv",
    dtype={"sensor_id": "string"}
)
distances = pd.read_csv(
    data_dir / "sensor_distances.csv.gz",
    dtype={"from_sensor_id": "string", "to_sensor_id": "string"}
)

print(speed.shape)       # (52116, 326)：1个时间列 + 325个站点列
print(stations.shape)    # (325, 4)
print(distances.shape)   # (8358, 3)
```

如果需要把宽表转换为“时间—站点—速度”长表，可以只转换本组所需的站点和时间范围，避免不必要的内存占用。

```python
chosen = ["400001", "400017", "400030"]
long_speed = speed[["timestamp", *chosen]].melt(
    id_vars="timestamp",
    var_name="sensor_id",
    value_name="speed_mph"
)
```

## 6. 开始分析前必须完成的检查

1. 明确分析对象是“检测站”“检测站—时间”还是“拥堵事件”；
2. 核对站点编号是否在三个数据文件中一致；
3. 说明0值处理规则；
4. 检查滚动窗口是否跨越了65分钟时间间隔；
5. 预测或预警任务按时间划分训练、验证和检验数据，不得随机打乱后再切分；
6. 先建立简单基准，再判断复杂方法是否真正带来改善；
7. 将结论限制在速度运行状态，不把相关性写成因果性。
